# Denial Prevention Dashboard Specification

## Purpose

This dashboard shows where revenue cycle workflow breakdowns appear before they become repeated denials, rework, delayed reimbursement, and patient confusion.

## Intended User

- Revenue cycle analyst
- Patient access lead
- Prior authorization coordinator
- Clinic manager
- Healthcare administration student portfolio reviewer

## Core Metrics

| Metric | Why It Matters |
|---|---|
| Total denied accounts | Shows denial volume |
| Denials by reason | Reveals root-cause categories |
| Average days in A/R | Shows reimbursement delay |
| Rework-required accounts | Shows staff burden |
| Denials by payer type | Shows payer-specific friction |
| Denials by service line | Shows operational risk area |

## Recommended Visuals

1. KPI Cards
   - Total accounts
   - Denied accounts
   - Average days in A/R
   - Rework-required accounts

2. Bar Chart
   - Denials by denial reason

3. Matrix Table
   - Service line by denial reason

4. Trend or Ranking Table
   - Highest days in A/R accounts

5. Workflow Risk Notes
   - Eligibility inactive
   - Authorization missing
   - Documentation incomplete

## Portfolio Insight

A denial dashboard should not only show what was denied. It should show which upstream workflow condition made the denial predictable.
