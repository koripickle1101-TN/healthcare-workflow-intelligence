# Kori Pickle Visual Brand System

## Status

Locked master brand identity system for Healthcare Workflow Intelligence.

This file is the master prompt layer for every portfolio visual, LinkedIn carousel, workflow map, GitHub preview, case-study graphic, dashboard mockup, and public-facing design asset.

## Brand Position

Healthcare Workflow Intelligence is a student-built healthcare administration portfolio focused on revenue cycle workflow analysis, prior authorization visibility, eligibility workflows, denial prevention, documentation quality, patient access operations, and healthcare workflow improvement.

The visual identity should communicate strategic healthcare operations thinking, clean workflow intelligence, and premium professional credibility.

## 2. Typography System

### Headlines

Use high-contrast editorial serif typography inspired by Didot or Playfair Display.

Headline rules:

- Large scale dominance
- Tight kerning
- Editorial authority
- Strong contrast
- Used for the main visual message

Preferred headline structure:

WORD arrow WORD

Examples:

VALIDATE → PERFORM

CONTROL → SCALE

CAPTURE → CONVERT

MAP → IMPROVE

VERIFY → PREVENT

### Supporting Text

Use clean sans serif typography inspired by Inter or Helvetica.

Support text rules:

- Light to medium weight
- High readability
- Clear spacing
- Professional healthcare operations tone

### Micro Text

Use micro text for labels and system markers.

Micro text rules:

- Wide letter spacing
- All caps
- Small scale
- Used sparingly

Examples:

REVENUE SYSTEM

INTELLIGENCE LAYER

PATIENT ACCESS NODE

DENIAL PREVENTION CHECKPOINT

## 3. Color System

### Primary Accent

Vols Orange: #FF8200

### Base

White: #FFFFFF

### Typography

Black: #111111

Deep Gray: #333333

### Structure

Warm Gray: #E8E2DC

Very light warm gray may be used for subtle panels, dividers, grid lines, and background structure.

### Color Rule

Orange is an accent only. It should create emphasis, hierarchy, and identity without overwhelming the design.

Do not use orange as a dominant background.

## 4. Layout DNA

Every design must follow one dominant focal system.

Allowed focal systems:

- Vertical flow
- Radial system
- Structured grid
- Center-heavy workflow map
- Left-context/right-data layout

Rules:

- Never use multiple competing focal points
- Maintain 40 to 50 percent whitespace
- Keep the design clean but not empty
- Use intentional asymmetry
- Center-heavy composition is preferred
- Right side can carry functional data
- Left side should allow context and breathing space

## 5. Component System

### Nodes

Nodes are a signature visual element.

Node rules:

- Circular shape
- Double ring
- Thin orange outer stroke
- Soft glow inside
- Minimal icon or short label
- Clean spacing around each node

### Connectors

Connector rules:

- Dotted or faded lines
- Slight motion flow
- Thin and light
- Never thick or heavy
- Should suggest workflow movement, dependency, or handoff

### Cards and Dashboard UI

Use cards for structured operational content.

Card rules:

- Rounded rectangles
- Light gray or warm gray background
- Thin borders
- Minimal icons
- Optional sparkline charts
- Clean dashboard-like spacing

## 6. Depth Style

Allowed:

- Soft glow
- Subtle gradients
- Layered spacing
- Light dimensional hierarchy

Not allowed:

- Hard shadows
- Heavy skeuomorphism
- Flat lifeless design
- Overly decorative effects
- Cute or playful styling

## 7. Signature Visual Traits

Every design should feel:

- Strategic, not decorative
- Editorial, not template-based
- Productized like a SaaS system
- Feminine precision: clean, controlled, premium, and exact
- Healthcare operations focused
- Workflow-intelligence driven

The brand should never feel soft, childish, generic, cluttered, or overly corporate in a cold way.

Every design should answer one of these operational questions:

- Where does the workflow break?
- Why does rework happen?
- What downstream impact does the breakdown create?
- What control point would reduce the problem?
