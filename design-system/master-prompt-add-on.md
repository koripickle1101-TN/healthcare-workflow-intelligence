# Master Prompt Add-On

Use this at the end of any visual design prompt for Healthcare Workflow Intelligence.

```text
Apply a consistent premium visual identity.

High contrast editorial serif headlines.
Clean sans serif supporting text.
Vols Orange #FF8200 accent system.
White background with warm gray structure.
Double-ring circular nodes with soft glow.
Dotted or fading connector lines.
Structured grid with intentional asymmetry.
40 to 50 percent whitespace for breathing room.

Footer must include:

Created by Kori Pickle

Below it, render a handwritten cursive signature:

Kori Pickle

Signature style:

Elegant feminine cursive.
Smooth flowing strokes.
Slight right slant.
Natural ink variation.
Black or dark gray ink.
Premium editorial feel.

Add minimal LinkedIn and GitHub icons below.
```

## Signature Reminder

The signature must be black or deep gray only. Never orange.

## Brand Colors

- Vols Orange: #FF8200
- White: #FFFFFF
- Black: #111111
- Deep Gray: #333333
- Warm Gray: #E8E2DC
