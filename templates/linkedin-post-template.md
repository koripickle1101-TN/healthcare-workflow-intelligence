# LinkedIn Post Template

## Hook

Write one direct sentence that names the operational problem.

Example:

Most denials do not start in billing. They start upstream.

## Context

Explain the workflow situation in plain language.

## Breakdown

Name the point where the workflow loses accuracy, ownership, timing, visibility, or trust.

## Impact

Explain how the issue creates rework, delays, denials, escalation, patient confusion, or revenue friction.

## Better Question

Add one thoughtful question that shifts the conversation from blame to workflow improvement.

Example:

Where did the workflow allow the error to move forward without a checkpoint?

## Practical Fix

Name one practical control point, checklist, tracker, dashboard, or escalation rule.

## Closing Line

End with a strong insight.

Example:

The goal is not more manual checking. The goal is better workflow visibility.
